# Milestone roadmap and build order
Status: proposal; no work started or time commitments.

M0 Validation: observe 20–30 actual phone-only developers; compare Replit/mobile code editors and single-vs-worker flow.
M1 Repo foundation: GitHub login, selected-repo App install, safe read-only browser.
M2 Mobile editor: code editing, local drafts, revision pinning and diff.
M3 Worker UI: role profiles, tool permissions, shared task board.
M4 Agent loop: one worker executing scoped tool plans, approved scratch patches and factual test reports.
M5 GitHub delivery: explicit user-authorized branch/commit/PR with idempotency and readback.
M6 Nano experiment: independent model benchmarks, native runtime only if device results good.
M7 (later): remote tests on isolated workers after cost and security review.
M8 (later): supported Android debug APK builds; no release signing default.

## Completion requirements
Each milestone must have: implemented scope, threats, automated and manual checks, real device test where relevant, acceptance evidence and updated decisions. No milestone passes because an LLM says it is done.

## Parallel development with multiple AI coding tools
One change owner per workstream, separate branch, independent reviewer, CI acceptance, no simultaneous edits to shared files without coordination. Keep docs current.
